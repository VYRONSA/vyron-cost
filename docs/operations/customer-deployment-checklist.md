# Customer Deployment Checklist

## Before Deployment
1. Confirm customer-approved deployment window.
2. Confirm backup completed and recorded.
3. Confirm release notes and rollback contact shared.
4. Confirm customer users are informed of any short maintenance window.

## During Deployment
1. Deploy production build.
2. Apply approved schema changes if any.
3. Validate login, dashboard, procurement, manufacturing, sales, invoicing, reporting, PDF, and email paths.
4. Monitor error logs and key business endpoints.

## After Deployment
1. Confirm customer sign-off on critical workflow checks.
2. Share deployment completion note with rollback window duration.
3. Archive evidence: build hash, migration state, validation outputs.
